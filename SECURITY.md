# Security Policy

## Supported Versions

The only supported version(s) are the latest release, or the latest git.

| Version               | Supported |
| --------------------- | --------- |
| latest git commit     | ✅        |
| latest stable release | ✅        |
| older stable release  | ❌        |
| older git commit      | ❌        |

## Reporting a Vulnerability

Have a vulnerability? Open an issue.
