# Security Policy

## Supported Versions

The only supported version(s) are the latest release, or the latest git.

| Version | Supported          |
| ------- | ------------------ |
| latest git commit | :white_check_mark: |
| latest stable release | :white_check_mark: |
| older stable release | :x: |
| older git commit | :x: |

## Reporting a Vulnerability

Have a vulnerability? Open an issue.
